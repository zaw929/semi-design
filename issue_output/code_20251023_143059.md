# 行号支持功能开发 —— 代码修改总结文档

## 1. 需求分析
本需求为 Semi Design 的 TextArea 组件增加“行号显示”能力，主要目标如下：
- 新增 4 个 props：`showLineNumber`（行号开关）、`lineNumberStart`（起始行号）、`lineNumberClassName`（扩展类名）、`lineNumberStyle`（扩展样式）。
- 在组件 DOM 结构上实现一个与原有 TextArea 并列的行号栏，行号内容根据文本行动态渲染，支持自定义宽度、样式。
- 确保行号栏与 textarea 滚动、resize、自动高度同步。
- 样式、色彩和宽度依赖 SCSS token 配置，保证主题可控及扩展性。
- 保证兼容性，新增功能不影响现有接口或行为。

该能力可提升多行文本编辑体验，便于开发场景下的代码、高级输入等应用，并为后续可拓展样式能力做准备。

---

## 2. 代码分析
本次需求涉及三个核心文件：
- `packages/semi-ui/input/textarea.tsx`：TextArea React 组件主入口，负责 props 定义、结构渲染、事件逻辑。
- `packages/semi-foundation/input/textarea.scss`：TextArea 组件样式文件，覆盖通用样式，需补充行号栏相关样式。
- `packages/semi-foundation/input/variables.scss`：TextArea 样式 token 配置，需要新增行号栏相关 token。

TextArea 组件本身已支持自动高度、resize、内容滚动等场景，具备 wrapper 主体、textarea、后缀栏等结构；需在 wrapper 中新增行号栏逻辑。

---

## 3. 修改方案
### 3.1 文件清单及目的
- 修改 1：`packages/semi-ui/input/textarea.tsx`
    - 新增、扩展 props 类型定义包括 `showLineNumber`, `lineNumberStart`, `lineNumberClassName`, `lineNumberStyle`。
    - 在 render 逻辑下，判断 props 显示行号栏（div），渲染对应内容。
    - 行号栏 DOM 与 textarea 并列布局，采用 flex，内容为 value 拆分后的行计数。
    - 监听 textarea scroll 事件，驱动行号栏同步滚动。
    - 支持自动高度、resize时行号栏高度匹配。
    - 赋予样式类如 `semi-input-textarea-linenumber`，支持扩展类名和内联 style。

- 修改 2：`packages/semi-foundation/input/variables.scss`
    - 新增 token 定义：
        - `$color-input_textarea-linenumber-bg: #f5f5f5; // 行号栏背景色`
        - `$color-input_textarea-linenumber-text: #999; // 行号文字色`
        - `$width-input_textarea-linenumber: 40px; // 行号栏默认宽度`
    - 放在 Color、Width 下合适分类。

- 修改 3：`packages/semi-foundation/input/textarea.scss`
    - 新增并完善行号栏样式，包括布局（flex）、宽度、背景色、文字色、边框等。
    - 使用 `$module` 变量规范样式前缀。
    - 使用上述 token 控制行号栏样式值。
    - 保证响应高度、滚动、兼容 resize 和 autosize 场景。
    - 禁止使用 !important，遵守样式规范。

### 3.2 关键代码 Diff（示例表述）
#### 3.2.1 `textarea.tsx`（伪代码摘要对比）
```diff
+ interface TextAreaProps {
+   showLineNumber?: boolean;
+   lineNumberStart?: number;
+   lineNumberClassName?: string;
+   lineNumberStyle?: React.CSSProperties;
+ }

// Wrapper DOM 修改：
- <div className="semi-input-textarea-wrapper"> ... <textarea .../> ... </div>
+ <div className="semi-input-textarea-wrapper" style={{display: 'flex', ...}}>
+   {showLineNumber && (
+     <div
+       className={classnames('semi-input-textarea-linenumber', lineNumberClassName)}
+       style={{
+         ...lineNumberStyle,
+         width: 'var(--width-input_textarea-linenumber)',
+         background: 'var(--color-input_textarea-linenumber-bg)',
+         color: 'var(--color-input_textarea-linenumber-text)',
+       }}
+     >
+       {Array.from({length: value.split('\
').length}).map((_, idx) => (
+         <div key={idx}>{(lineNumberStart || 1) + idx}</div>
+       ))}
+     </div>
+   )}
+   <textarea ... onScroll={onTextAreaScroll} ... />
+ </div>

// 新增 scroll 同步/高度同步等逻辑
```

### 3.3 兼容性说明
- 所有新增 props 均为可选，默认关闭行号功能；原 API 无改变。
- 行号栏只在展示时影响 DOM，无副作用隔离问题。
- 样式扩展和 token 配置均遵守设计系统约定，便于定制化。
