# TextArea 行号功能代码修改总结文档

## 1. 需求分析
本次需求旨在增强 Semi Design 的 TextArea 组件，为用户提供行号显示功能。核心能力包括：
- 新增 `showLineNumber` 以控制是否显示行号；
- 支持 `lineNumberStart` 设定起始值，默认1；
- 行号栏允许传入自定义 className 和 style，提升灵活性；
- 行号需与 textarea 内容及滚动实时同步，确保体验无延迟。
该能力有助于提升开发者和内容编辑场景的可用性，满足代码编辑、日志查看等需求。

## 2. 代码分析
Semi Design 组件采用 adapter 层和 foundation 层分离设计：
- adapter 层主逻辑位于 `packages/semi-ui/input/textarea.tsx`，所有对 TextArea 的扩展都应在此实现；
- 类型声明在 `packages/semi-ui/input/interface.ts`；
- 样式相关设计（包含设计 token、样式结构等）位于 `packages/semi-foundation/input/variables.scss` 和 `packages/semi-foundation/input/textarea.scss`；
- 入口导出文件 `packages/semi-ui/input/index.tsx`；
- 单元测试 `packages/semi-ui/input/__test__/textArea.test.js`、故事包 `packages/semi-ui/input/_story/textarea.stories.tsx`。
项目已存在滚动容器同步、辅助div布局等相关范式，可参考 scrollList、codeHighlight、inputNumber 组件内部对齐与同步逻辑。

## 3. 修改方案
本次变更覆盖类型定义、主组件逻辑、样式、入口文件、测试与演示，具体如下：

### 3.1 类型声明修改
**涉及文件**：`packages/semi-ui/input/interface.ts`

#### 修改内容（diff）：
- 新增 `showLineNumber?: boolean;`、`lineNumberStart?: number;`、`lineNumberClassName?: string;`、`lineNumberStyle?: React.CSSProperties;`。类型定义以单独声明并复用。

#### 目的说明：
便于 TextArea 主组件和外部用户完整传参，保证类型推断兼容。

---

### 3.2 主逻辑实现
**涉及文件**：`packages/semi-ui/input/textarea.tsx`

#### 修改内容（diff）：
- props 结构扩展上述4个参数并向下传递；
- 新增 `renderLineNumbers` 辅助方法，参数包含行数、起始值、className、样式；
- TextArea 渲染主流程分支判断 `showLineNumber`，如为 true，则以合适布局（flex/div结构）插入行号栏（复用 renderLineNumbers 函数输出）；
- textarea/行号栏 onScroll 实现同步滚动，监听 textarea 的 scroll 事件，将 scrollTop 设给行号栏；
- 每次 value 变更时重算行号数目（根据 `split('
')` 得到行数），保证内容一致性。

#### 目的说明：
符合 RFC 功能扩展预期，保证性能与结构无侵入主流程，保持兼容性。

---

### 3.3 设计 token 与样式
**涉及文件**：
- 设计 token：`packages/semi-foundation/input/variables.scss`
- 样式文件：`packages/semi-foundation/input/textarea.scss`

#### 修改内容（diff）：
- 在 `variables.scss` 中新增：
  ```scss
  $color-input_textarea-lineNumber-bg: #f5f7fa; //行号栏背景色
  $color-input_textarea-lineNumber-border: #dde3ea; //行号栏右侧边框色
  $color-input_textarea-lineNumber-text: #a3afbf; //行号文本色
  $font-input_textarea-lineNumber: 'Roboto Mono', monospace; //行号字体
  $spacing-input_textarea-lineNumber-padding: 0 8px; //行号栏水平内边距
  $width-input_textarea-lineNumber: 32px; //行号栏宽度
  ```
- 在 `textarea.scss` 中新增 `.#{module}-textarea-lineNumber` 及子元素样式：
  - 背景色、边框色、字体、宽度、对齐方式、分割线等均使用新 token；
  - 结合 $prefix/$module 变量自动生成样式前缀，严禁硬编码前缀。

#### 目的说明：
统一设计语言，支持主题扩展，保证视觉一致性。新类名和样式完全独立，不影响原有结构。

---

### 3.4 入口导出
**涉及文件**：`packages/semi-ui/input/index.tsx`

#### 修改内容：
- 确保 TextAreaProps 类型的新参数能完整导出，保证对外接口一致性。

#### 目的说明：
便于外部直接引用扩展后的能力。

---

### 3.5 测试与故事
**涉及文件**：
- 单元测试：`packages/semi-ui/input/__test__/textArea.test.js`
- 故事包：`packages/semi-ui/input/_story/textarea.stories.tsx`

#### 测试修改内容：
- 增加用例覆盖行号栏渲染、同步滚动（模拟 scroll 和内容变化）、className/style 用法、起始行号等。

#### 故事修改内容：
- 新增典型场景演示：显示/不显示行号、自定义样式、大文本同步滚动。

#### 目的说明：
确保新功能在各种边界条件下表现稳定、API 完善；帮助用户快速理解能力边界和使用方法。

## 总结
本次 TextArea 行号功能改造严格遵循组件分层与设计规范，所有新能力通过可选参数与独立样式实现，全面兼容原有主流程与扩展场景。通过 token 与样式分离设计，支持主题化，且所有逻辑变化都有完整测试和示例支撑，代码结构清晰，可维护性强。
