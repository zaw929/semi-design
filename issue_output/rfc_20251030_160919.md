# RFC: TextArea 组件行号功能技术方案

## 1. 需求背景

根据 issue，TextArea 组件需新增「行号显示」功能，具体要求：

- 新增 `showLineNumber: boolean` 控制是否显示行号。
- 新增 `lineNumberStart: number` 控制起始行号（默认 1）。
- 新增 `lineNumberClassName: string` 实现自定义行号栏 class。
- 新增 `lineNumberStyle: CSSProperties` 支持行号栏自定义样式。
- 行号栏要和正文内容滚动同步，无延迟。
- 行号样式、布局需支持复写和半定制，并遵循 Semi Design 既有风格。
- 需考虑合理 token 拓展和样式适配。

## 2. 实现方案

### 2.1 文件改动路径说明

- **组件逻辑与 API**：  
  - `packages/semi-ui/input/textarea.tsx`
- **样式结构**：  
  - `packages/semi-foundation/input/textarea.scss`
- **token 定义**（如需新增）：  
  - `packages/semi-foundation/input/variables.scss`

export interface TextAreaProps extends Omit<React.TextareaHTMLAttributes<HTMLTextAreaElement>, OmitTextareaAttr> {

export interface TextAreaLineNumberProps {

### 2.3 UI 结构调整与业务逻辑

#### 组件结构调整（textarea.tsx）

- **渲染结构**须变为：  
  父容器横向 flex → 左侧行为号栏（自定义类名和 style），右侧为 textarea 原核心区。
- 可复用 wrapper 样式，行号区与 textarea 在同一滚动上下文下。
- 行号栏内容需根据 value（自动换行/rows）& lineNumberStart 生成对应数组、动态渲染（如 `<div>1</div><div>2</div>`...）。
- 行号栏及 textarea 区域需 scroll 事件联动：  
  - 行号栏 scrollTop/scrollLeft 要跟随 textarea 内容同步，监听 textarea onScroll 并同步对应 DOM。  

#### 拟新增/修改主要函数

- **渲染行号栏**  
```typescript
private renderLineNumberBar(): React.ReactNode
// 使用: 根据 value、rows、lineNumberStart 以及可选托管函数生成行号列表，内联自定义 className、style
```

- **滚动同步处理**  
```typescript
private handleSyncScroll(e: React.UIEvent<HTMLTextAreaElement>)
/*
  1. 在 textarea 的 onScroll 事件回调里同步 lineNumberBar 的 scrollTop，保证行号栏与内容同步滚动。
  2. 若行号栏采用 position: sticky 或 absolute，也需设置 scrollTop 或 translateY。
*/
```

#### 组件主渲染方法调整
- 在 render 内，根据 `showLineNumber` 判断是否渲染行号栏结构，并适配样式。行号栏与主区同级，flex 布局，行号栏宽度可写死变量或加 token 定制。

### 2.4 样式方案

#### SCSS 结构新增
`packages/semi-foundation/input/textarea.scss`
- 新增：`.#{$module}-textarea-lineNumberBar` 类，支持灵活宽度、文本右对齐、颜色 token 适配。
- 若无适配 token，建议在 `variables.scss` 新增 token：
  - $width-input_textarea-lineNumberBar: 32px; // 行号栏宽度
  - $color-input_textarea-lineNumberBar-bg: var(--semi-color-fill-0); // 行号栏背景
  - $color-input_textarea-lineNumberBar-text: var(--semi-color-text-2); // 行号栏文字色
  - $spacing-input_textarea-lineNumberBar-right: 8px; // 行号栏与 textarea 内容分割的间距

```scss
.#{$module}-textarea-lineNumberBar {
  position: absolute;
  left: 0;
  top: 0;
  width: $width-input_textarea-lineNumberBar;
  height: 100%;
  background: $color-input_textarea-lineNumberBar-bg;
  color: $color-input_textarea-lineNumberBar-text;
  text-align: right;
  padding-right: $spacing-input_textarea-lineNumberBar-right;
  box-sizing: border-box;
  user-select: none;
  font-family: inherit;
  font-size: inherit;
  /* 支持传入自定义行号 class & style */
}
```
- 在原 wrapper 外层加 position:relative，使行号栏和 textarea 共存（行号栏可绝对定位或采用 flex 布局）。

### 2.5 token 新增建议

若需支持行号栏样式 token，建议在
`packages/semi-foundation/input/variables.scss` 新增：

```scss
$width-input_textarea-lineNumberBar: 32px; // 行号栏宽度
$color-input_textarea-lineNumberBar-bg: var(--semi-color-fill-0); // 行号栏背景色
$color-input_textarea-lineNumberBar-text: var(--semi-color-text-2); // 行号栏文字颜色
$spacing-input_textarea-lineNumberBar-right: 8px; // 行号栏文本右侧 padding
```

---

### 2.6 其他注意事项

- 参数优先 props 逐层传递，保持原有结构不变，新增功能不侵入原主线逻辑。
- 自定义样式优先通过 className/style，且暴露足够样式钩子。
- 保证类型声明规范、样式变量使用 $module/$prefix，禁止硬编码前缀、禁止 !important。
- 国际化无需涉及（本次未涉及多语言文本）。
- 测试用例可暂不考虑，按需补充 storybook 示例。

---

## 总结

本方案将为 TextArea 组件新增强行号支持，采用横向结构嵌入行号栏区域，并实现内容滚动同步。所有扩展均以非侵入形式融入原逻辑与样式体系，并补充样式变量/ token 实现全面可定制化。
