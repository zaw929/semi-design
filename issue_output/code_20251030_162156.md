# TextArea组件行号功能代码修改总结

## 需求分析

本次需求旨在为 Semi Design 的 TextArea 组件增加“行号显示”功能，提升用户多行文本编辑体验，尤其对代码编辑及文本格式化场景非常有价值。具体需求包括：
- 新增 `showLineNumber` 控制行号开关。
- 新增 `lineNumberStart` 控制起始行号。
- 新增 `lineNumberClassName`、`lineNumberStyle` 支持样式定制。
- 行号栏与内容滚动同步。
- 组件需遵循 Semi Design 风格，token 可定制。

---

## 代码分析

- **组件入口**：`packages/semi-ui/input/textarea.tsx`  
  负责TextArea主要渲染、逻辑、props类型定义。
- **样式文件**：`packages/semi-foundation/input/textarea.scss`  
  控制TextArea的整体与细节样式。
- **设计Token文件**：`packages/semi-foundation/input/variables.scss`  
  定义各类可自定义SCSS变量。

---

## 修改总结

### 1. 组件及类型定义 `textarea.tsx`

#### 新增与调整内容

- **类型拓展**：
  ```diff
  +     showLineNumber?: boolean;
  +     lineNumberStart?: number;
  +     lineNumberClassName?: string;
  +     lineNumberStyle?: React.CSSProperties;
  ```
  - 在 `TextAreaProps` 类型中新增上述字段。
  - 新增并导出 `TextAreaLineNumberProps` 类型：包含行号栏相关属性定义。

- **新增内部方法**：
  - `renderLineNumberBar`：根据 value/rows/lineNumberStart 动态渲染行号列表。
  - `handleSyncScroll`：使行号栏滚动与 textarea 区域同步。

- **主渲染逻辑优化**：
  - 判断 `showLineNumber`，采用横向 flex 布局，左侧为行号栏、右侧为文本域；
  - 行号栏支持自定义 className/style；
  - 文本区注册 scroll 事件，联动行号栏滚动。

#### 结构变更片段示例

```diff
-        return (
-            <div className={wrapperCls} ... >
-                ...
-            </div>
-        );
+        if (showLineNumber) {
+            return (
+                <div className={wrapperCls} style={{display: 'flex', position: 'relative'}}>
+                    <div style={{position: 'relative', height: '100%', flexShrink: 0}}>
+                        {this.renderLineNumberBar()}
+                    </div>
+                    <div style={{flex: 1, position: 'relative'}}>
+                        <textarea {...itemProps} ref={this.setRef} onScroll={this.handleSyncScroll} />
+                        {this.renderClearBtn()}
+                        {this.renderCounter()}
+                    </div>
+                </div>
+            );
+        }
```

### 2. 样式文件 `textarea.scss`

#### 新增样式

- 增加行号栏 `.input-textarea-lineNumberBar` 类，控件宽度、右对齐文字、配合 token 定制颜色、间距等，具体样式如下：

```scss
.#{$module}-textarea-lineNumberBar {
  position: absolute;
  left: 0;
  top: 0;
  width: $width-input_textarea-lineNumberBar;
  height: 100%;
  background: $color-input_textarea-lineNumberBar-bg;
  color: $color-input_textarea-lineNumberBar-text;
  text-align: right;
  padding-right: $spacing-input_textarea-lineNumberBar-right;
  box-sizing: border-box;
  user-select: none;
  font-family: inherit;
  font-size: inherit;
  z-index: 1;
  display: flex;
  flex-direction: column;
  justify-content: flex-start;
}
```

### 3. 设计Tokens `variables.scss`

#### 新增 token 和注释

- 行号栏相关常量：
  ```scss
  $width-input_textarea-lineNumberBar: 32px; // 行号栏宽度
  $color-input_textarea-lineNumberBar-bg: var(--semi-color-fill-0); // 行号栏背景色
  $color-input_textarea-lineNumberBar-text: var(--semi-color-text-2); // 行号栏文字色
  $spacing-input_textarea-lineNumberBar-right: 8px; // 行号栏与textarea内容分割的间距
  ```
- 符合 semi token 规范，可被样式文件引用定制。

## 修改原因及目的说明

- 满足业务需求，实现高可定制性行号功能。
- 充分利用 SCSS token 提高组件皮肤化和扩展能力。

- 所有新增逻辑均为可选、非侵入式，对原有主线逻辑零污染。
